山河把地图、时间线与 AI 探索放进同一个本地故事工作台。

## 下载与安装

- **Apple Silicon（M 系列）**：下载文件名包含 `macos-arm64` 的 `.dmg` 或 `.zip`。
- **Intel Mac**：下载文件名包含 `macos-x64` 的 `.dmg` 或 `.zip`。
- 系统要求：**macOS 13.5 或更新版本**。内置 Node.js，使用时无需安装 Node 或运行开发服务。
- 打开 DMG，把「山河」拖到 Applications；ZIP 解压后也可以把 App 拖到「应用程序」。

当前为 **ad-hoc 签名、未经 Apple 公证的测试包**，不是 Developer ID 签名发行版。macOS 首次打开可能提示无法验证开发者；确认下载来自本仓库后，可按系统「隐私与安全性」中的提示允许打开。

## 开始探索

从苏轼的一生、五代十国、江南漫游开始，或导入在线版导出的故事。在左下角「模型设置」连接本机 Codex 或模型 API，即可通过对话补充事件和地图标记。

故事保存在本机。替换 App 不会覆盖故事库；更新前也可以导出 JSON 备份。

各架构均附带 `.sha256` 文件，可以在下载目录运行 `shasum -a 256 -c <文件名>.sha256` 核对 DMG 和 ZIP。
