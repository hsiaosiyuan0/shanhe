# GitHub 仓库信息

推荐沿用「山河」这个产品名。仓库名用 `shanhe`，英文写作 **Shanhe**，副标题用 **Story Atlas**。

| 仓库名               | 适合的方向                                         |
| -------------------- | -------------------------------------------------- |
| **`shanhe`（推荐）** | 简短，延续现有中文品牌，能够覆盖历史、人物与旅行。 |
| `shanhe-atlas`       | 在品牌后补充地图属性，看到名字就有地图集的联想。   |
| `story-atlas`        | 英文语义直接，突出故事与地图的结合。               |

## Description

中文：

```text
山河：把地图、时间线与 AI 对话放在一起的本地故事工作台。探索历史、人物与旅行，支持本地 Codex、模型 API 和 SQLite 保存。
```

英文：

```text
A local-first story atlas for history, biographies, and journeys. Explore maps and timelines with AI, connect local Codex, and keep stories in SQLite.
```
