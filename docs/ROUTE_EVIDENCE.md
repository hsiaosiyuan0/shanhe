# 苏轼首次赴京：行程资料与地图精度

当前只整理 1056 年首次出蜀赴京，1057 年是登第年份。不能从「1037 年生于眉山」直接连到「1057 年少年登第」，把这二十年误表示成一次旅途。

## 资料

1. [苏轼在汴十二年大事记 · 开封党史方志网](https://www.kfdsw.com/index/detail/id/2834.html)，2025-06-18。记述 1056 年离成都，经剑门关、秦岭、宝鸡、长安、渑池赴京。1059 年再度赴京则沿岷江、长江至江陵，转陆路北上，属于另一趟行程。
2. [尧军：苏轼陆路出蜀路线考探 · 三苏祠博物馆](https://www.sscbwg.cn/suxueyanjiu/924.html)，网页发布于 2022-04-16，原载《中国苏轼研究》第六辑（2016），248–264 页。讨论「经阆中出褒斜」与「过剑门至凤翔」等路线分歧，重建金牛道—陈仓故道方案；作者指出若干驿址、秦岭支道及嘉陵江沿线是否兼用舟行仍待进一步考证。

## 图上怎么表达

- 整体是陆路赴京，图中采用尧军的重建方案，不能称为学界已一致确认的实际道路。
- 眉州、成都、剑门、凤翔、长安、渑池、汴京有文献或研究引文提及。它们的现代概略位置用于地理对照，不代表精确古城/关隘位置。
- 绵州、梓潼作为金牛道方向参照；利州、三泉、金牛驿、兴州、河池驿、两当、凤州、大散关等是所选方案中的概略控制点。研究推定不等于证实停驻。
- 秦岭段以灰色虚线表示，交通方式注明「水陆细节待考」。其余两段以棕色虚线表示陆路走廊，但地点之间的道路仍未逐段复原。
- 半透明带只是屏幕上的概略走廊提示，其像素宽度不代表量化的误差范围。线段来自相邻地区概略坐标，不是古道 GIS 数据；没有调用现代导航，没有借地形最短路径或平滑曲线补造证据。
- 缩小时收起次要地点文字，放大或点击点位仍可查看完整说明；分段列表始终列出沿途地点。

## 尚未完成

1059 年经三峡、江陵的水陆行程、1061 年赴凤翔及其他生平行程尚未绘制。当前没有按历史年代变化的河道、道路与行政疆界，也没有自动查阅文献、比较路线方案的工具。地图现代底图只能作参照。

新增行程应先整理独立的出行日期和证据，再绘制与证据精度相称的几何。地点出现记录、经过次序、交通方式、具体道路须分别核验，不能因为其中一项有出处，就将整条轨迹升级为已查证。
